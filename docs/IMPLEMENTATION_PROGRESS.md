## Current pass: company persistence and first drafting workflow

- Connected the existing server work to setup/sign-in, company/sample switching, protected navigation, scoped data, account management, export, owner acceptance, and company-wide availability counts.
- Added a server-side OpenAI Responses adapter and a Spanish AI drafting/review experience. Generation never silently overwrites a draft; the user reviews the suggestion and explicitly selects replacement fields. Catalog rates are applied by the server.
- Added pre-generation missing-information warnings, saved review questions, model/date provenance, the exact brief used, and recent generation history. These complete the local Phase 3A showcase without requiring a live provider.
- Added a provider-neutral messaging contract and dedicated owner-only send action. Exact drafts are queued before transport, final delivery or failure is recorded without rewriting content, proposals are issued only after confirmed transport success, and a local showcase channel never contacts a client.
- Added provider-neutral inbound intake for the showcase, duplicate external-ID protection, exact source-message/revision evidence, ambiguous-response linking review, and owner notifications. Ordinary record edits cannot forge the protected evidence.
- Added an explicit post-acceptance production checklist. Confirmed allocations must cover every catalog item in the accepted current revision for the full event window, production tasks must have owners, and the server rejects premature preparation or execution. Closeout is also blocked until tasks are complete and allocations are returned or cancelled.
- Completed the local structured-layout milestone with calibrated image references, measurement evidence, geometry validation, equipment-quantity reconciliation, exact revision snapshots, automatic local draft recovery, reusable event templates, and self-contained SVG plan export. These actions never reserve inventory or rewrite proposals.
- Completed the connected 3D local milestone with shared selection, versioned saved cameras, simple brand surfaces, explicit placeholder status, revision-linked PNG snapshots, and bounded/adaptive scene rendering. The simulator makes no engineering, photorealistic lighting, or acoustic claim.
- Completed Spanish-first shell coverage for navigation, route headings, primary actions, common controls, statuses, notifications, acceptance review, proposal drafting, and the 2D/3D design controls used in the milestone journey. Stored client content, business record names, and internal identifiers are never translated automatically. Additional copy refinement can continue inside later module work without reopening Phase 1.
- Fixed restoring company sessions at a direct record URL, and semantic dirty-state comparison so reordered response fields do not mark a saved draft as unsaved.
- Live AI quality, actual company examples, WhatsApp, full backup recovery and production deployment remain unverified. No live model call or client message was sent.
